# 第七章随堂练习

## 一、单选题

### 1. AGC 环路中使用低通滤波器的目的是\_\_\_\_\_\_\_\_。

- A. 避免反调制现象
- B. 减小静态误差
- C. 提高输出信号的动态范围
- D. 增大能处理信号的带宽

**参考答案：** A

### 2. 延迟 AGC 电路的优点是\_\_\_\_\_\_\_\_。

- A. 减小电路的功率消耗，提高功率效率
- B. 简化电路设计，易于实现
- C. 提高电路的灵敏度
- D. 减小电路的残差

**参考答案：** C

### 3. 以下不属于 AGC 电路组成部分的是\_\_\_\_\_\_。

- A. 振幅检波器
- B. 可变增益放大器 VGA
- C. 电压比较器
- D. 混频器

**参考答案：** D

## 二、多选题

### 4. 构成一个高阶锁相环，需要有\_\_\_\_\_\_\_\_\_\_\_\_。

- A. 环路滤波电路
- B. 鉴相器
- C. VCO
- D. 鉴频器

**参考答案：** A、B、C

### 5. 锁相环的基本特性包括\_\_\_\_\_\_\_\_\_\_\_。

- A. 锁定时无频差
- B. 锁定时无相差
- C. 良好的窄带跟踪特性
- D. 良好的调制跟踪特性
- E. 良好的门限特性

**参考答案：** A、C、E

### 6. 以下关于反馈控制电路描述中正确的是\_\_\_\_\_\_\_\_\_\_\_\_\_。

- A. 反馈控制电路只能对外部来的干扰进行调节
- B. 反馈控制电路可以自动对信号进行调节
- C. 反馈控制电路必然会存在残差
- D. 任一反馈控制电路将同时比较输出信号和参考信号的所有参量，如幅度、频率、相位等

**参考答案：** B、C

## 三、单选题

### 7. 已知一阶锁相环路中正弦鉴相特性鉴相器的 Ad = 2V ，压控振荡器的 A0 = 10kHz /V ，自由振荡频率 f0 = 1MHz ，则当输入频率为 0.99MHz 的正弦信号时，环路的稳态相差为 \_\_\_\_。

- A. $\frac{1}{2}$
- B. $\frac{\pi}{6}$
- C. $-\frac{\pi}{6}$
- D. $-\frac{1}{2}$

**参考答案：** (1) C

## 四、填空题

### 8. 当锁相环路进入锁定过程时，瞬时角频差不断\_\_\_\_(增大、减小)，控制角频差不断\_\_\_\_(增大、减小)，但两者之和恒等于开环角频差。

**参考答案：** (1) 减小；(2) 增大

### 9. PLL 电路可以利用\_\_\_\_误差来消除频率误差。

**参考答案：** (1) 相位
