# 第三章随堂练习

## 一、多选题

### 1. 以下属于谐振回路功能的有

- A. 滤波
- B. 移相
- C. 阻抗变换
- D. 无源放大

**参考答案：** A、B、C

### 2. 以下属于并联谐振回路特点的有\_\_\_\_\_\_\_\_\_\_

- A. 谐振时回路端口阻抗最低
- B. 并联谐振又被称为电流谐振
- C. 当输入信号频率低于谐振频率时，并联谐振回路呈现出电感特性
- D. 谐振频率为【原选项公式失效，待核对】

  参考：理想 LC 谐振频率为 $f_0 = \frac{1}{2\pi\sqrt{LC}}$；无法据此确定失效图片中的原公式。

**参考答案：** B、C

### 3. 以下属于串联谐振回路特点的有\_\_\_\_\_\_\_\_\_\_

- A. 谐振时回路电流最大
- B. 串联谐振又被称为电流谐振
- C. 当输入信号频率低于谐振频率时，串联谐振回路呈现出电感特性
- D. 谐振角频率为 $\omega_0 = \frac{1}{\sqrt{LC}}$（根据题意及参考答案补写，原图已失效）

**参考答案：** A、D
