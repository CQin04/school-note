# 第六章随堂练习

## 一、单选题

### 1. 设某信号的频率为 1GHz，则根据天线理论可知，为使信号能被有效辐射，天线的尺寸至少应为\_\_\_\_\_\_\_

- A. 1cm
- B. 3cm
- C. 5cm
- D. 10cm

**参考答案：** B

### 2. 所谓基带信号，是指\_\_\_\_\_\_\_\_\_\_

- A. 用来携带信息的高频振荡波，如正弦信号、方波等
- B. 已经完成调制，即将送至天线发射出去的大功率信号
- C. 从消息变换过来的原始信号
- D. 频率在 100MHz 以下的信号

**参考答案：** C

### 3. 所谓模拟调制是指采用\_\_\_\_\_\_\_信号对载波进行调制。

- A. 模拟基带信号
- B. 数字基带信号
- C. 低频信号
- D. 高频信号

**参考答案：** A

### 4. 所谓振幅调制是指调制信号改变了高频载波的\_\_\_\_\_\_\_\_\_\_。

- A. 振幅
- B. 相位
- C. 频率
- D. 带宽

**参考答案：** A

- B. 2V

**参考答案：** C

### 6. 设已调波的表达式为vAM (t) = (1+ 0.5cos2兀 ×103 t)cos2兀 ×106 t(V) ，则其载波频率为\_\_\_\_\_\_\_\_\_\_\_

### 7. 设已调波的表达式为vAM (t) = (1+ 0.5cos2兀 ×103 t)cos2兀 ×106 t(V) ，则其调制信号频率为\_\_\_\_\_\_\_\_\_\_\_

## 二、填空题

### 10. 暂时留空

**参考答案：** 暂时留空

### 11. 集电极调幅时，高频谐振功率放大器工作在\_\_\_\_状态;基极调幅时，高频谐振功率放大器工作在\_\_\_\_状态。

**参考答案：** (1) 过压；(2) 欠压

### 12. 二极管大信号峰值包络检波中两种主要的非线性失真是\_\_\_\_失真(也被称为对角切割失真)和\_\_\_\_失真

**参考答案：** (1) 惰性；(2) 负峰切割

### 13. 设某基带信号的带宽为10kHz，则采用普通AM调制后的已调信号带宽为\_\_\_\_Hz，采用DSB调制后的已调信号带宽为\_\_\_\_Hz，采用SSB调制后的已调信号带宽为\_\_\_\_Hz。

**参考答案：** (1) 20k；(2) 20k；(3) 10k

### 14. 所谓相干信号，是指接收端提供的与载波同频且\_\_\_\_的本地振荡信号。

**参考答案：** (1) 同相

### 15. 设某发射机所输出调幅波中的载波功率为1000W，则其可能输出的最大总功率为\_\_\_\_W。

**参考答案：** (1) 1500

### 16. 设参与正交调幅的两路基带信号的带宽分别为20kHz和15kHz，则已调波的带宽应为\_\_\_\_kHz。

**参考答案：** (1) 40
