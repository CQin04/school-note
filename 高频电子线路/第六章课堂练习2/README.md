## 二、多选题

### 6. 以下关于间接调频电路的描述中正确的是\_\_\_\_\_\_\_\_\_

- A. 间接调频具有比直接调频更高的中心频率稳定度
- B. 间接调频一般不能直接取得频偏过大的信号

## 三、填空题

### 7. 已知频率为 100MHz 的载波被频率为 10kHz 的正弦信号进行频率调制，最大频偏为 100kHz。

(1)此时的调频指数mf = \_\_\_\_，带宽\_\_\_\_kHz。

(2)若vΩm 加倍，kf 不变，则调频指数mf = \_\_\_\_，最大频偏为\_\_\_\_，带宽为 \_\_\_\_kHz。

(3)若vΩm 与 kf 都加倍，则调频指数mf = \_\_\_\_，最大频偏为\_\_\_\_，带宽为 \_\_\_\_kHz。

(4) 若在第 2 问的基础上将调制信号频率加倍，则调频指数mf = \_\_\_\_，最大频偏为 \_\_\_\_，带宽为\_\_\_\_kHz。

**参考答案：** (1) 10；(2) 200；(3) 20；(4) 200kHz；(5) 400；(6) 40；(7) 400kHz；(8) 800；(9) 10；(10) 200kHz；(11) 400

### 8. 将一个调频波通过倍频器后，其中心频率和最大角频偏将会\_\_\_\_(增大、减小、不变)，相对角频偏将会\_\_\_\_(增大、减小、不变)，此时调制指数会\_\_\_\_(增大、减小、不变)

**参考答案：** (1) 增大；(2) 不变；(3) 增大
