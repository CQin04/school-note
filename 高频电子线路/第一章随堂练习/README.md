# 第一章随堂练习

## 一、单选题

### 1. 以下不属于通信系统框图组成部分的是\_\_\_\_\_\_\_\_\_\_

- A. 输入变换器
- B. 接收设备
- C. 输出变换器
- D. 马达

**参考答案：** D

### 2. 设某器件的伏安特性为 i = 1+ v+ v² ，若同时输入两个频率为 6kHz 和 7kHz 的信号，则输出信号中将不包括如下频率的信号\_\_\_\_\_\_\_\_\_\_

- A. 12kHz
- B. 13kHz
- C. 14kHz
- D. 15kHz

**参考答案：** D

## 二、多选题

### 3. 以下属于通信系统模型一部分的为\_\_\_\_\_\_\_\_\_\_

- A. 输入变换器
- B. 发送设备
- C. 信道
- D. 接收设备
- E. 输出变换器

**参考答案：** A、B、C、D、E

### 4. 设某器件的伏安特性为 i = 1+ v+ v² ，则当输入频率为 1kHz 的电压信号时，输出电流的频率分量包括\_\_\_\_\_\_\_\_\_\_

- A. 直流分量
- B. 1kHz
- C. 2kHz
- D. 3kHz

**参考答案：** A、B、C

### 5. 设某器件的伏安特性为 i = 1+ v+ v³ ，则当输入频率为 1kHz 的电压信号时，输出电流的频率分量包括\_\_\_\_\_\_\_\_\_\_\_\_\_\_

- A. 直流分量
- B. 1kHz
- C. 2kHz
- D. 3kHz

**参考答案：** A、B、D

### 6. 电磁波在空间的传播途径包括\_\_\_\_\_\_\_\_\_\_

- A. 量子传播
- B. 地波
- C. 天波
- D. 直线波

**参考答案：** B、C、D

### 7. 在连续波调制中，使用信号 X 去控制高频振荡信号的某一参数，使之随着 X 的变化规律而变化，信号 X 又被称为\_\_\_\_\_\_\_。

- A. 基带信号
- B. 载波
- C. 已调波
- D. 调制信号

**参考答案：** A、D

## 三、填空题

### 8. 发送设备的两大主要任务是\_\_\_\_和\_\_\_\_。

**参考答案：** (1) 调制；(2) 放大

### 9. 信源经输入变换器后转换成的电信号又被称为\_\_\_\_信号，其形式不一定适合在信道上传输。

**参考答案：** (1) 基带
