# 01-电子系统的焊接技术

## 一、单选题

### 1. 对于我们平时焊接所用的焊锡丝，描述正确的是______？ P2

- A. 焊锡丝是实心的焊锡组成。
- B. 焊锡丝是空心的，中间添加助焊剂
- C. 焊锡丝是空心的，中间是空气。

**参考答案：** B

### 2. 焊接后导致元器件烧毁，最可能的原因是______？ P2

- A. 烙铁头在一个焊点焊接时用力过猛
- B. 烙铁头在一个焊点停留时间太短
- C. 烙铁头在一个焊点停留太久，且温度过高

**参考答案：** C

### 3. 烙铁头的保养与维护中，烙铁头氧化、黑化的“最重要”原因是______？

- A. 通电时间长
- B. 未使用高档焊锡丝
- C. 不挂锡保养，长时间暴露在空气中
- D. 未定期清理烙铁头碳化物

**参考答案：** C

### 4. 使用烙铁焊接的正确步骤是______？ P2

1. 焊点加助焊剂，烙铁接触后加焊锡
2. 挂锡保养烙铁头
3. 海绵清洁烙铁头再放入助焊剂保护烙铁头
4. 接通电源待温度升高

- A. 2-3-4-1
- B. 4-3-2-1
- C. 4-2-3-1
- D. 1-2-3-4

**参考答案：** B

### 5. 电烙铁的工作原理是将____能量，转换为____能量？ P1

- A. 化学能，热能
- B. 电能，热能
- C. 电能，化学能

**参考答案：** B

## 二、多选题

### 6. 烙铁头不沾锡的原因有______？ P3

- A. 烙铁已损坏
- B. 烙铁手握姿势不对
- C. 烙铁头已严重氧化
- D. 长时间通电，不挂锡保养烙铁头，且温度过高

**参考答案：** A、C、D

### 7. 焊接完成后，如何通过观察法，避免虚焊或假焊______？ P3

- A. 焊点上的焊锡量宜多不宜少
- B. 焊点应为半球状
- C. 焊点外表光滑、均匀
- D. 没有明显的气泡、凹陷

**参考答案：** B、C、D

### 8. 使用烙铁焊接的注意事项有哪些？（ ） P2

- A. 选择合适的焊锡丝和助焊剂
- B. 烙铁头挂锡保养
- C. 焊接前先洗手
- D. 正确的姿势

**参考答案：** A、B、D
