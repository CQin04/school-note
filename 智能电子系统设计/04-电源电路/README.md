# 04-电源电路

## 一、单选题

### 1. 根据电学知识，直流电、交流电在电路中的表示符号为：________ P67

- A. 直流：Difficult Current (DC) 交流：Alter Current (AC)
- B. 直流：Alternating Current (AC) 交流：Direct Current (DC)
- C. 直流：Direct Current (DC) 交流：Alternating Current (AC)

**参考答案：** C

### 2. 人们通常把输入电压低于多少伏特的电压变换过程，称为DC-DC转换？___________ P67

- A. 24V
- B. 72V
- C. 36V
- D. 48V

**参考答案：** B

### 3. 在特殊情况下，想要得到比输入电压更高的电源，可以采用什么电路？________ P69

- A. Foot电路
- B. Bast电路
- C. Boost电路
- D. Fast电路

**参考答案：** C

## 二、多选题

### 4. 在电路中，常见的稳压方式主要类型有哪一些？______ P67

- A. 模拟稳压电路
- B. 稳压三极管电路
- C. 稳压二极管，电压超过就泄流
- D. 开关型稳压电路

**参考答案：** A、C、D

### 5. 根据课程所学，DC-DC稳压电路在工作中，可能会发生哪些故障？________ P69

- A. 停止工作或输出电压达不到要求
- B. 输出电压超标或输出电流超标
- C. 不接输入却持续输出电流
- D. 输入端短路

**参考答案：** A、B、D
