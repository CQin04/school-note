## 课程资料维护

- 课程文件按课程名称归类；已有目录结构和命名优先保留，不为统一格式改动现存作业链接。
- 每门课程尽量维护课程 README，列出作业、实验、题目数量、复习入口以及待整理事项。
- 所有新资料上传前检查个人信息、教师课件、题图与转载授权，确认适合公开。
- 不把课程网页里的 Cookie、账号、学生姓名、学号、成绩、访问令牌或含签名的链接提交到仓库。
